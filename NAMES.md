# Name candidates

**Chosen: `cud`** (2026-06-11).

OCaml-themed (desert/camel/water — the tool re-pours the same stdin while you
adjust the mechanism). All were unclaimed on opam as of 2026-06-11.

- **shaduf** — hand-levered irrigation device: work an interactive lever (the
  arg line) to pour the same water (stdin) again each pull. Obscure but
  googleable, like `dune` / `oasis`.
- **noria** — water wheel that endlessly re-lifts the same stream, bucket by
  bucket: auto-rerun in one word.
- **qanat** — underground channel feeding an oasis: the pipe(line) theme,
  literally.
- **cud** — camels chew the cud: re-processing the same input over and over.
  Three letters, cheeky, very typeable.
- **bactrian** — the two-humped camel: run it again.
- **caravan** — the command keeps making the same trip with a re-packed load.

Rename checklist when one is picked: `dune-project` (name + package),
`bin/dune` (`public_name`), `test/e2e/dune` (`%{bin:...}` + INE env var),
README, this file.
